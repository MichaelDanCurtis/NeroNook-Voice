# Nero Voice
Independent native voice plugin. Read README.md. Keep microphone, recognition, hotkeys and speech synthesis here, not in NeroNook. Use only the shared SDK for optional conversational providers; no account/token imports. Local Apple Speech first; no silent cloud fallback. No ambient recording, wake word or system-audio capture. Start recording only from a direct user control. Preserve editable transcript review before copying/sending. Bound audio queues and duration, serialize lifecycle, reject late callbacks and stop on shutdown/sleep. Maintain OmniVoice provenance. No automatic subagent delegation.
